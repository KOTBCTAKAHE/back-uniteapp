# UNITEAPP Backend

VPN-сервер для объединения устройств в виртуальную локальную сеть.

## Запуск

```bash
go build -o uniteapp-server ./cmd/server/
./uniteapp-server
```

По умолчанию сервер слушает порт **7655** (TCP + UDP).

```bash
./uniteapp-server -tcp-port 7655 -udp-port 7655
```

## Протокол UNITEAPP (UAP)

Собственный минималистичный сетевой протокол.

- **TCP** — управляющий канал (подключение, keepalive, отключение)
- **UDP** — канал данных (пересылка IP-пакетов между клиентами)

### Формат пакета

```
[Magic: 2 bytes "UA"] [Version: 1 byte] [Type: 1 byte] [SessionID: 4 bytes] [PayloadLength: 2 bytes] [Payload]
```

### Процедура подключения

1. Клиент подключается по TCP
2. Отправляет `HELLO` с именем устройства
3. Сервер отвечает `WELCOME` с виртуальным IP, маской подсети, IP сервера и MTU
4. Клиент начинает отправлять `DATA` пакеты по UDP
5. Сервер маршрутизирует пакеты между клиентами

### Виртуальная сеть

- Подсеть: `10.10.0.0/24`
- Сервер: `10.10.0.1`
- Клиенты: `10.10.0.2` — `10.10.0.254`
- Поддержка broadcast для обнаружения в LAN-играх
